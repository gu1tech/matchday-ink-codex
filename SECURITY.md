# Security

This is a single-user trusted-LAN prototype, not an Internet-facing hosted service. The display API uses unencrypted HTTP. Do not port-forward it or expose the USB setup service publicly.

Never include API keys, Wi-Fi passwords, private configuration or network-identifying screenshots in public issues. For a suspected credential exposure, revoke the affected credential before discussing the incident. Use GitHub private vulnerability reporting if enabled; otherwise contact the maintainer privately through an available contact on their profile. Do not post exploit details or secrets in a public issue.

This review candidate has no formal security audit or guaranteed support window.
