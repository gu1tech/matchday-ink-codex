# Contributing

Use small changes with a concrete problem, expected behaviour and relevant verification. Keep public code, UI text and documentation in English. Do not add dependencies or abstractions without explaining the need.

Run the checks in `docs/development.md`. Default tests must not require personal credentials, live network services or paid API calls. Use clearly synthetic fixtures and avoid distributing licensed datasets.

Document AI assistance and review generated output. Label implemented, locally tested, hardware-tested and planned work separately. Never claim prediction accuracy from synthetic tests. Do not commit caches, credentials, personal network settings or unrelated print experiments.
